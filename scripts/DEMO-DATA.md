# 20 учебных записей (локальный контур)

Данные подключаются автоматически, пока `NEXT_PUBLIC_DEMO` не `false` и API не задан.
PIN для всех учебных записей: **1234**

Ключ хранилища: `vs-kr-citizen-platform-v15` (после обновления откройте сайт заново / очистите старый ключ).

## Демо-входы (пароль `1111`)

| Роль | Логин |
|------|--------|
| Администратор | `admin` |
| Приёмная | `spravochnaya` |
| Председатель | `predsedatel` |
| Зам. Председателя | `ispolnitel` |

## Коды для показа

Актуальный список после запуска: `scripts/DEMO-20.txt`

| Код | Статус / этап | Для чего на презентации |
|-----|---------------|-------------------------|
| VS-2026-0001…0003 | pending_review | Подтвердить / отказать (приёмная) |
| VS-2026-0004…0005 | confirmed / registered | Начать подготовку |
| VS-2026-0006…0007 | under_review | Завершить подготовку |
| VS-2026-0008 | ready → chairman | Протокол приёма (председатель) |
| VS-2026-0009 | ready → deputy | Приём у заместителя |
| VS-2026-0010…0011 | in_control | Поручения (зам. председателя) |
| VS-2026-0012 | closed | Ответ направлен, без оценки гражданина |
| VS-2026-0013, 0020 | closed + оценка | Закрытые / повторное обращение |
| VS-2026-0014 | rejected | Отказ |
| VS-2026-0015 | cancelled | Отмена |
| VS-2026-0016 | no_show | Неявка |
| VS-2026-0017 | rescheduled | Перенос |

Проверка статуса гражданином: `/appointment-status` → код + PIN `1234`.

Повторный прогон тестов: `node scripts/e2e-admin-full.mjs`
